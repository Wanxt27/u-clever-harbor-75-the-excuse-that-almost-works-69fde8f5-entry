A single original one-line excuse a gamer texts the boss to skip work on GTA 6 launch week, written by `main.ts` to `/output/entry.txt` (one line, 92 characters, 18 words, inside the 140-character gate and the 20-word cap).

> sorry boss, my car died in the midnight launch queue at GAME, tow truck can't come till noon

Run it with Node 22+:

```sh
node main.ts
```
